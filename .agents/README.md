# Memory bank

Schema and maintenance rules for this project's persistent knowledge.

- `memory.md` — persistent knowledge. Append `## <date> — <topic>` entries; keep decisions and
  gotchas; never silently delete prior entries. Supersede a wrong entry by appending a newer one.
- `state.md` — always-current status. Rewrite with: Goal, Today's progress, Blockers, Next actions.
  Update it last, after code and docs land.
- Root `AGENTS.md` — stable repo guidance for every tool. Re-read at session start.

No secrets, tokens, or private URLs in memory files.
